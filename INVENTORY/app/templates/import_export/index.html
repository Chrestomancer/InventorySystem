Help & Information
Export

Export your data to Excel or CSV format for backup or analysis purposes. You can export all data or specific sections.

Import

Import data from Excel or CSV files. The system will:

  • Update existing items if they match by SKU
  • Create new items if they don't exist
  • Skip rows with errors (and report them)
Templates

Download sample templates to see the required format for importing data. The templates include:

  • Inventory Template: For importing items and inventory records
  • Platforms Template: For importing sales platforms
Important: When importing inventory items, the "Name" field is required for new items. For existing items (matched by SKU), any fields you include will update the existing data.
