Database Backup Management

About Backups

Backups allow you to save the current state of your inventory database and restore it if necessary.

  • Create Backup: Creates a snapshot of your current database
  • Restore Backup: Replaces your current database with a selected backup
  • Download Backup: Downloads the backup file to your computer
Warning: Restoring a backup will replace all current data with the data from the backup file. This action cannot be undone.
